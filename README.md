# Focus App Project
Taking control of distractions. By teens, for teens. This product is designed for students who want to improve their relationship with technology. It creates a personalized plan to reduce social media usage, without the confusion and ineffectiveness of setting your own limits. Personalized reccomendations and planning guide users to stop doomscrolling for good. Also features a MediaMonster (virtual pet) as motivation. 

# Features
- Customizable micro-intervention when opening blocked apps: writing prompt, breathing exercise, message from virtual MediaMonster.
- Tracks screentime averages and monitors change over time.
- Based on screentime data imported from phone, creates personalized reccomendations for realistic time limits & session frequency
- Rather than having users blindly choose limits, app learns from patterns
- Smart features adapt strategy based on user's adherence to the limits

# Project History
This app started as an idea at a summer camp to create FocusFrames & OptiFocus, a pair of glasses and an app that track focus metrics in real-time using pupilometry. However, we decided to pivot to a simpler app that helps mitigate distractions. So no hardware is necessary; the app now stands alone!
